# IndicSent-M Research Paper LaTeX Codebase for Overleaf

This directory contains the complete, publication-ready IEEE-format research paper for **IndicSent-M**:
*Title: "IndicSent-M: Multimodal Cross-Attention Network for Sentiment Analysis in Code-Mixed Indic Memes"*

## 🚀 Quick Setup on Overleaf (Option 1: 1-Click Upload)
1. Go to [Overleaf](https://www.overleaf.com/).
2. Click **New Project** $\to$ **Upload Project**.
3. Select the pre-packaged zip file:
   - `IndicSent_M_Overleaf_Paper.zip` (located on your Desktop or in the project root).
4. Click **Recompile**. The full two-column IEEE paper with TikZ architecture diagram and tables will compile automatically!

## 📋 Manual Setup (Option 2: Copy-Paste)
1. In Overleaf, create a **Blank Project**.
2. Replace the contents of `main.tex` with [paper/main.tex](file:///Users/bindanm/IndicSent-M/paper/main.tex).
3. Create a new file named `references.bib` and paste the contents of [paper/references.bib](file:///Users/bindanm/IndicSent-M/paper/references.bib).
4. Hit **Recompile**.
